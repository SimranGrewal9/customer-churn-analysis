# Customer Churn Analysis (EDA Project)

## Overview
This project analyzes telecom customer churn using Python.

## Tools Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Scikit-learn

## Steps

### Day 1-4: Data Cleaning and Exploration
- Data cleaning
- Missing value analysis
- Data visualization
- Churn pattern analysis

### Day 5-8: Machine Learning Model
- Data preprocessing
- Encoding categorical variables
- Train-test split
- Logistic Regression model training
- Decision Tree model training
- Model evaluation using accuracy score
- Confusion matrix analysis
- Classification report generation
- Comparison of model performance

## Goal
To understand why customers leave the service and build machine learning models to predict customer churn.
